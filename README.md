# 특이민원 원터치 대응

특이민원 발생 시 **고지 멘트·조치 사항·적용법조**를 바로 확인하는 직원용 모바일 앱(PWA)입니다.
근거자료: 「특이민원 예방 및 대응요령」(2025. 8., 고용노동부 민원운영팀)

- 주소: **https://minwonsafe.github.io/safer/** (내부 채널로만 공유)
- 홈 화면 이름: 원터치대응 / 앱 안 제목: 특이민원 원터치 대응

## 주요 기능

| 메뉴 | 내용 |
|---|---|
| 위기 상황 대응 | 전화통화·대면방문·기타 상황별 고지 멘트와 조치 사항 |
| 직원 보호·지원 | 법률·보험·심리·휴식 지원 안내 |
| 관련 법적 근거 | 위법행위별 적용 조문과 형량 |
| 참고 대응 사례 | 판결로 확인된 사례 |
| 인쇄·PDF 저장 | 책상용 1장 또는 전체 자료 출력 |

- **발생 경위 정리**: 입력한 내용을 이미지·PDF로 저장해 관리부서 담당자에게 카톡·메일로 직접 첨부합니다. 입력 내용은 기기 밖으로 나가지 않고 앱에도 남지 않습니다
- **뒤로 가기**: 폰의 뒤로 버튼·제스처가 앱 안에서 한 단계씩 돌아갑니다
- **설정**(첫 화면 오른쪽 위): 글자 크기(보통·크게), 내 전화기(흰색·검정), 홈 화면 설치
- 한 번 접속해 두면 인터넷이 끊겨도 열립니다

## 휴대폰에 설치하기

- **갤럭시**: 첫 화면의 설치 카드 또는 설정 → 홈 화면 설치. 안 보이면 브라우저 메뉴(⋮) → 앱 설치
- **아이폰**: Safari 아래 공유 버튼(□↑) → 홈 화면에 추가

## 파일 구성

| 파일 | 위치 | 역할 |
|---|---|---|
| `index.html` | 최상위 | 앱 본체 (화면·데이터·기능 전부) |
| `manifest.json` | 최상위 | 설치 정보 (앱 이름·아이콘·색) |
| `service-worker.js` | 최상위 | 오프라인 동작·자동 업데이트 |
| 아이콘 PNG 4개 | 최상위 | 앱 아이콘 |
| `check_app.js` | **tests 폴더** | 배포 전 자동 검사 |
| `deploy.yml` | .github/workflows 폴더 | 검사 통과 시에만 자동 배포 |

## 수정할 때 지킬 것

- 파일은 위 표의 **위치 그대로** 올립니다. `check_app.js`를 최상위에 올리면 검사가 돌지 않습니다
- `manifest.json`·아이콘·`service-worker.js`를 고치면 `service-worker.js`의 `CACHE_NAME` 숫자를 올립니다 (`safer-v2` → `safer-v3`)
- 홈 화면 이름(`short_name`)은 **6자 이하** — 넘으면 아이폰에서 잘립니다. 이름을 바꿔도 이미 설치한 아이폰은 지우고 다시 추가해야 바뀝니다
- 올린 뒤 **Actions 탭에서 초록 체크**를 확인합니다. 빨간색이면 배포가 멈추고 기존 화면이 유지되며, 항목을 열면 ✗로 원인이 나옵니다
